# A / B / C

## A transformations

noun → mechanism; implementation → primitive; symptom → bottleneck;
claim → falsifier; architecture → dependency graph; workflow → critical path;
domain language → domain-independent mechanism; repetition → compilation;
waiting → scheduling; uncertainty → information-acquisition.

## B

Parallel specialists (primary, code, benchmarks, counterexamples, analogs,
history, baselines, failures) return structured evidence. One synthesizer
mutates. `NO_UPDATE` is first-class.

Extract per find: claim, mechanism, evidence, scope, boundary, contradiction,
transferable principle, implication, confidence delta.

## C

Trigger when experiment value > research value. One hypothesis, one
intervention, predicted metric, control, ablation, holdout, rollback.

## Anti-patterns (fail the skill)

generic search/summarize loops; source hoarding; forced 25 waves;
secondary-source confidence; vocab-only analogy; rewrite-before-experiment;
self-validation; novelty-from-ignorance.
